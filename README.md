# 2° B 

Instrucciones:
1. Extraer el ZIP (no debe contener node_modules en el ZIP).
2. Abrir terminal en la carpeta del proyecto.
3. Ejecutar: npm install
4. Ejecutar: npm start
5. Abrir en navegador: http://localhost:3000

Funciones incluidas:
- CRUD completo de eventos (crear, listar, ver detalle, editar, eliminar).
- Relación eventos:  proveedores e invitados (se muestran nombres en el detalle).
- Endpoints API disponibles en /api/* (devuelven JSON).
